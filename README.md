# Todo CLI

Python CLI task tracker (standard library only) built with Antigravity CLI for GDG DevFest Hanoi 2026.

## Usage

    python3 todo.py add "Buy groceries"
    python3 todo.py list
    python3 todo.py complete 1

Tasks are saved to tasks.json.

## Tests

    python3 -m unittest -v test_todo.py
